# 参与与反馈 · Contributing

欢迎通过 Issues 提交问题或改进建议。请说明工具版本、Windows 版本、操作步骤、期望结果与实际结果。音频问题请描述格式与参数；无需公开私人文件或完整本地路径。

Bug reports and suggestions are welcome through Issues. Include the tool version, Windows version, steps, expected behavior, and actual behavior. For audio problems, describe the format and settings without exposing private files or full local paths.

修改源码后请运行构建和检查脚本。保持中文、英文界面与说明一致；勿提交音频、游戏数据、EXE、临时日志或凭据。维护者偶尔查看反馈，无法承诺响应时间。项目许可范围见 [LICENSING.md](LICENSING.md)。

Run the build and check scripts after changes. Keep Chinese and English text aligned. Do not commit game data, audio, EXEs, temporary logs, or credentials. Feedback is reviewed occasionally, without a response-time commitment. See [LICENSING.md](LICENSING.md) for licensing scope.
